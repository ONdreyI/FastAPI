1. Открыть терминал в корне проекта.
2. Ввести **poetry new xlxsproject** - создает проект с необходимыми папками (**xlxsproject** - название проекта)
3. В самом проекте открываем терминал и набираем **poetry config --list**
4. Переключаем виртуальное окружение внутрь проекта **poetry config virtualenvs.in-project = true**
5. Добавление новых пакетов через **poetry add** (например fastapi[all])
6. Инициализируем alembic init alembic (для переноса информации в СУБД)
7. В файле alembic.ini снимаем хэштег со строки # file_template = %%(year)d_%%(month).2d_%%(day).2d_%%(hour).2d%%(
   minute).2d-%%(rev)s_%%(slug)s
8. Импортируем FastAPI.
   Создаём экземпляр **app**.
   Пишем декоратор операции пути (такой как **@app.get("/")**).
   Пишем функцию операции пути (**def root(): ...**).
   Запускаем сервер в режиме разработки (**uvicorn main:app --reload**).
9. **black ./users** - набрать в коммандной строке для форматирования целого модуля в "Black"
10. Добавлен плагин **Database Navigator**
